# Security Policy for Kusmus AI

## Supported Versions

Kusmus AI actively maintains and secures the following versions of the Sovereign Agent framework and internal core logic.

| Version | Supported          | Support Expiration |
| ------- | ------------------ | ------------------ |
| 5.1.x   | :white_check_mark: | Active             |
| 5.0.x   | :x:                | Deprecated         |
| < 5.0   | :x:                | Deprecated         |

## Reporting a Vulnerability

Security is a core tenet of our mission for Institutional Autonomy. If you discover a security vulnerability within the Kusmus AI platform, our Sovereign API routing layer, or our deployment architectures, we strongly request that you report it to us immediately.

### How to Report

Please **do not** report security vulnerabilities through public GitHub issues or community forums.

Instead, email your findings directly to our security team at:
**akporurho@proton.me**

### What to Include

To help us remediate the issue safely and quickly, please include:
- A detailed description of the vulnerability and its potential impact.
- The affected component, URL, or infrastructure layer (e.g., Sovereign Proxy API, Session Manager).
- Step-by-step instructions to reproduce the vulnerability (proof of concept, scripts, or HTTP request dumps).
- Your timezone and availability for potential follow-up questions from our cyber-forensics team.

### Our Commitment

We take all disclosures seriously. You can expect:
1. **Initial Acknowledgment:** Within 24-48 hours of your submission.
2. **Status Updates:** Regular updates on the evaluation and remediation of the vulnerability.
3. **Credit:** Unless you prefer to remain anonymous, we will credit you in our release notes for responsibly disclosing the issue.

Thank you for helping keep Kusmus AI and our institutional partners secure.
